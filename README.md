## 🎯 Featured Project

### [🛠️ ARM Cross-Compilation Template](https://github.com/RezaSaadat1/armhf_cross_compile)
A comprehensive VSCode template for C/C++ cross-compilation targeting ARM devices with integrated CI/CD pipeline.

**Key Features:**
- ✅ Ready-to-use VSCode development environment
- ✅ Docker DevContainer support for consistent builds
- ✅ Multi-architecture ARM support (32-bit & 64-bit)
- ✅ Remote debugging capabilities
- ✅ GitHub Actions CI/CD integration
- ✅ Compatible with Raspberry Pi, BeagleBone, and other ARM boards
